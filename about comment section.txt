  What this DOESN'T do yet

  Here's the catch — right now this class does nothing. Visit /api/posts/ and you'll still hit the old PostListAPIView, because PostViewSet
  isn't connected to any URL yet.

  APIView plugs into path('posts/', PostListAPIView.as_view()). ModelViewSet doesn't work that way — it can't go in a path() directly, because
  one ViewSet handles multiple URL shapes (/posts/ AND /posts/<id>/) and path() only knows one URL at a time.

  So we need a different gadget — a router — that takes one ViewSet and generates all the matching URL patterns automatically.
